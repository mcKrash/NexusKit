## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   npm install recharts lucide-react
   ```

2. **Create admin user:**
   ```bash
   npx prisma studio
   # Set user role to 'ADMIN'
   ```

3. **Access dashboard:**
   ```
   http://localhost:3000/admin/dashboard
   ```
